What I Want to Build
I want to build a laptop recommendation system.
The system should allow a user to enter what they are looking for in a laptop, including:
Budget
Purpose — e.g. gaming, programming, editing, studying, office work, etc.
RAM
Storage
CPU
GPU
Brand preference
Other available specifications if required.
The user should not have to provide every specification. Budget and purpose are the main requirements, while the other specifications can be optional.
The system should use the user's requirements to find and rank the laptops that best match their needs.
The final output should show the recommended laptops along with their important specifications and price.
The system should also provide a simple explanation of why each laptop was recommended.
If there is no exact match, the system should provide the closest suitable alternatives rather than simply returning no results.
The final product should have a simple user interface where a user can enter their requirements and view the recommendations.
